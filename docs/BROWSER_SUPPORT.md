## Testing Methodology

- Validate frontend authentication, dashboard, profile, notifications, earnings, and submission flows.
- Validate admin settings, reports, and payout screens on supported desktop browsers.
- Test responsive layouts at mobile (<640px), tablet (640px-1024px), and desktop (>1024px) breakpoints.
- Check keyboard navigation, focus management, and visible validation feedback.
- Confirm there are no blocking JavaScript console errors during core workflows.
- Re-run smoke tests after any asset, workflow, or caching change.
- Use device emulation and real-device testing for final smoke coverage.
