
# Browser Support

## Supported Browsers
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+
- Chrome for Android (latest two major versions)
- Safari on iOS 14+

## Testing Methodology
1. Validate frontend authentication, dashboard, profile, notifications, earnings, and submission flows.
2. Validate admin settings, reports, and payout screens on supported desktop browsers.
3. Test responsive layouts at mobile (<640px), tablet (640px-1024px), and desktop (>1024px) breakpoints.
4. Check keyboard navigation, focus management, and visible validation feedback.
5. Confirm there are no blocking JavaScript console errors during core workflows.
6. Re-run smoke tests after any asset, workflow, or caching change.
